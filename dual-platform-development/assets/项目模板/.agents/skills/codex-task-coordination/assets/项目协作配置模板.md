# 项目任务协作配置模板

填写后保存到调用项目；这是规则模板，不是运行记录或操作授权。

## 项目与入口

- 项目名称：待填写。
- 项目根：待填写，可相对本配置文件定位；以下路径均相对该项目根。
- 项目 AGENTS.md、工程说明与必要技能：待填写。
- 技能来源：记录实际 `codex-task-coordination/SKILL.md` 路径；不要从技能位置推导项目根。

## 仓库及权限

| 稳定仓库 ID | 实际路径 | 平台或职责 | 规则入口 | 本地提交授权来源 |
| --- | --- | --- | --- | --- |
| 待填写 | 待核实 | 待填写 | 待核实 | 待核实，不能沿用其他项目授权 |

- 职责按实际角色和源码归属登记：多 Agent／多独立任务协调者负责调度、审查及已授权集成，不接管已分配给其他执行者的源码；单 Agent 和模块内部主 Agent 可直接实现、修复及验证。公共路径指定唯一维护者，调整已分配范围前先核对在途动作并完成职责交接。
- 创建聊天、互发消息、源码修改与集成：记录本批用户的真实授权来源和边界。
- 协作资料是否允许暂存、提交、改写历史：待明确。
- 推送、发布和外部写入：按各自实际授权，不从本地权限推导。

独立任务内部可以由主 Agent 直接执行或按项目规则派生子 Agent；所属聊天汇总结果并对外交付，内部委派不扩大职责、源码范围或授权，也不替代长期独立聊天身份。

## 协调层级与集成归属（按需）

按 [多级独立聊天协议](../references/hierarchical-coordination.md) 登记实际协调组、父子长期目录及当批关联；工作量不足时省略层级。每组维护自己的批次与消息，逐层转述必要依赖；每个真实仓库目标交付线指定唯一集成负责人。上层核对冻结汇总，接续分别扫描各组及待转述项，不将工具描述为递归调度器。已有运行记录原位保留，项目统一验收台账维护方式不变。资料路径区分顶层／原单层默认与各子组独立长期目录、批次路径，通过父组 `children` 关联，不共写父组控制资料。

源码基线与最终集成遵循 [分支基线规则](../references/code-delivery.md#启动分支开发基线与-worktree)：实际启动时按仓库登记当前分支及 HEAD，模块和共享 worktree 从该起点创建；目标分支可持续推进，终版集中 rebase 后快进回原目标。项目配置不填写固定活动分支，实际快照及动作保存在批次记录。

## 共享维护与依赖（按需）

- 是否设置独立共享任务及触发依据：按[技能中的两类共享任务](../SKILL.md#共享任务的职责与触发条件)判断；可以不设置，不因参与 iOS、Android 两端而默认增加角色。
- 设置时登记：仓库内共享代码／跨仓库公共依赖、权威来源的真实仓库与路径、唯一维护者、实际消费者、可写与只调用范围、接入方式和验证依据。各端适配归属分别明确，角色类型不扩大既有授权。
- 接入记录：同仓库公共原始 SHA → 各 worktree 副本 → 规范集成 SHA；跨仓库依赖则记录来源版本／哈希 → 消费仓库接入提交 → 本仓库集成及验证。仅契约对齐不创建共享代码任务；无本轮共享工作时不等待共享交付。

## 资料与接续

- 源码工作区根：按真实源码仓库位置确定，默认与原源码仓库并列为其父目录下的 `worktree/`；同父目录可共用，不同父目录按仓库分别登记，显式相对路径从本配置声明的项目根换算，已有明确路径定制保留；按[目录与对应规则](../references/worktree-layout.md)组织需求/平台/任务，登记真实聊天与源码分支，共享按需、协调工作区优先安全复用。
- 长期任务目录：待填写。
- 新批次协调目录：待填写路径模式，实际运行使用绝对路径。
- 接续说明：待填写。
- 证据与构建产物目录：待填写，并遵守机器和项目约束。
- 已有批次原位保留，恢复先运行 `recover`，核对真实聊天、Git 和证据；不重建消息或执行意图。

## 验收及项目扩展

- 验收类型：UI / 非 UI / 混合，按实际范围填写。
- 验收规则入口、工具入口、执行者及最终通过条件：待填写。
- UI 项目：登记设计依据、参与平台、页面/状态身份、主题与方向矩阵、截图原图和构建元数据、验收册更新命令、失效与历史保留规则。
- 非 UI 项目：登记契约、测试、构建及产物证据；不强制 UI 工具或截图。
- 集成后的复验范围、设备/共享资源排队、未验证项处理：待填写。
- 项目特有资源清理、缺失功能反馈、平台参考限制：按适用项目填写。

## 配置变更

新批次在长期目录与批次资料中登记配置路径并留存快照和哈希。规则或验收变化保留历史，通知受影响任务，重新核对在途动作和证据。配置不包含密钥，也不作为自动执行命令的脚本。
