# 项目任务协作配置模板

填写后保存到调用项目；这是规则模板，不是运行记录或操作授权。

## 项目与入口

- 项目名称：待填写。
- 项目根：待填写，可相对本配置文件定位；以下路径均相对该项目根。
- 项目 AGENTS.md、工程说明与必要技能：待填写。
- 技能来源：记录实际 `codex-task-coordination/SKILL.md` 路径；不要从技能位置推导项目根。

## 仓库及权限

| 稳定仓库 ID | 实际路径 | 平台或职责 | 规则入口 | 本地提交授权来源 |
| --- | --- | --- | --- | --- |
| 待填写 | 待核实 | 待填写 | 待核实 | 待核实，不能沿用其他项目授权 |

- 主任务只协调、调度、只读审查及已授权集成；实现和验证由执行任务负责，公共路径指定唯一共享维护者。
- 创建聊天、互发消息、源码修改与集成：记录本批用户的真实授权来源和边界。
- 协作资料是否允许暂存、提交、改写历史：待明确。
- 推送、发布和外部写入：按各自实际授权，不从本地权限推导。

## 资料与接续

- 长期任务目录：待填写。
- 新批次协调目录：待填写路径模式，实际运行使用绝对路径。
- 接续说明：待填写。
- 证据与构建产物目录：待填写，并遵守机器和项目约束。
- 已有批次原位保留，恢复先运行 `recover`，核对真实聊天、Git 和证据；不重建消息或执行意图。

## 验收及项目扩展

- 验收类型：UI / 非 UI / 混合，按实际范围填写。
- 验收规则入口、工具入口、执行者及最终通过条件：待填写。
- UI 项目：登记设计依据、参与平台、页面/状态身份、主题与方向矩阵、截图原图和构建元数据、验收册更新命令、失效与历史保留规则。
- 非 UI 项目：登记契约、测试、构建及产物证据；不强制 UI 工具或截图。
- 集成后的复验范围、设备/共享资源排队、未验证项处理：待填写。
- 项目特有资源清理、缺失功能反馈、平台参考限制：按适用项目填写。

## 配置变更

新批次在长期目录与批次资料中登记配置路径并留存快照和哈希。规则或验收变化保留历史，通知受影响任务，重新核对在途动作和证据。配置不包含密钥，也不作为自动执行命令的脚本。
