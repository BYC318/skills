- 项目根：`.`，相对本文件所在目录；以下项目路径均从项目根解析。
- 项目规则：[AGENTS.md](AGENTS.md)；工程与各端规则入口：[双端项目说明.md](双端项目说明.md)。

- 独立任务技能：[codex-task-coordination](.agents/skills/codex-task-coordination/SKILL.md)；运行不依赖初始化技能的安装位置。

## 仓库与权限

| 稳定仓库 ID | 实际路径 | 平台或职责 | 规则入口 | 本地提交授权来源 |
| --- | --- | --- | --- | --- |
| 待登记 | 未绑定 | 按实际参与平台或模块登记 | 从项目说明核实 | 待核实当前用户授权 |

- 跨聊天协调者负责调度、只读审查和已授权的 Git 集成，不接管已分配给其他执行者的源码；单 Agent、模块或共享任务内部主 Agent 可在自身授权范围实现、修复及验证。公共路径登记唯一维护者，调整已分配范围前先核对在途动作并完成职责交接。
- 创建聊天、互发协作消息、源码修改、提交及本地集成：实际启动前记录当前用户授权及边界；不能沿用其他项目授权。
- 协作资料是否允许暂存、提交、改写历史：待核实。
- 推送、PR、发布及业务外部写入：分别遵守实际授权。

独立任务内部可以由主 Agent 直接执行或按项目规则派生子 Agent；所属聊天汇总结果并对外交付，内部委派不扩大职责、源码范围或授权，也不替代长期独立聊天身份。

## 资料与接续

- 长期任务目录：待建立，建议项目内 `任务记录/独立任务目录.json`；正式使用登记真实聊天与历史批次。
- 新批次协调目录：待核对本机共享存储和项目产物约束，使用按项目、任务和批次隔离的实际绝对路径；不放在会被切换或集成的源码 worktree 内。
- 接续说明：实际启动后使用项目内 `任务记录/<任务名称>.md`，保留需求修订、未关闭依赖和下一步。
- 构建、日志及证据目录：遵守当前机器、用户与源码仓库规则，实际验证前核实；不在通用模板固定本机磁盘路径。
- 已有批次原位恢复；实际接续时核对配置快照、真实聊天、Git 及证据，不重建消息、执行意图或历史交付。

## 验收与配置变更

- 验收类型、参与平台、契约、验证入口和最终通过条件：待按本次任务明确；工程未绑定前不记为已就绪。
- UI 工作按项目实际设计来源、页面与状态、主题/方向矩阵、截图工具及台账要求取证；非 UI 工作按契约、构建和测试验收，不强制截图或 Figma。
- 集成后由执行者复验受影响范围；共享设备串行使用，保留历史及真实来源，缺失条件记为未验证。
- 新批次登记本配置实际绝对路径并保存快照和哈希；变更时保留历史并核对受影响动作及证据。配置不包含密钥，也不是自动执行命令的脚本。
