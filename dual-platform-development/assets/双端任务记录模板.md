## Agent 执行方式与分工

- 跨聊天协作：未启用，或已主动启用 `codex-task-coordination`；记录用户启用或明确接续的来源。
- 当前聊天的身份与职责：采用独立聊天协作时，引用长期目录、当前批次及项目配置的实际入口；不要在此复制维护第二份聊天目录。
- 聊天内部执行方式及依据：主 Agent 直接执行／按需派生多个子 Agent；说明工作量、依赖和文件边界。此项与跨聊天协作可同时启用。
- 当前聊天主 Agent：负责分配范围内的内部调度、共同契约、结果汇总和证据核对；采用独立聊天协作时统一提交对外交付，跨聊天主任务负责最终集中验收。
- 实际编码与协调范围：登记自身可直接实现的源码、明确留给自己的工作及已分配给其他执行者的范围。单 Agent 和模块内部主 Agent 可编码、修复和验证；协调者不接管已分配源码。
- 职责交接（有调整时）：记录在途动作、实际工作区、原执行者停止相关写入的确认及新归属；执行者不可用不自动转移职责。
