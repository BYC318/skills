# 内存评审清单

仅勾选已从代码或测量中确认的项目；“看起来更省内存”不算验证。

## 所有权与生命周期

- [ ] 新增长期引用的所有者和释放边界明确。
- [ ] delegate、双向对象关系和逃逸闭包未形成不必要的强引用环。
- [ ] `unowned` 的生命周期不变量可证明；否则使用 `weak` 并处理 `nil`。
- [ ] Timer、观察者、订阅、回调令牌和异步任务会在功能生命周期结束时停止或解除。
- [ ] 取消后的异步工作会响应取消，过期结果不会回写当前状态。

## 大对象、图片与缓存

- [ ] 大图按实际展示像素降采样，没有先完整解码再缩小的重复峰值。
- [ ] 图片请求在复用、换源和页面退出时取消，并在回写前校验身份。
- [ ] 内存缓存有按业务测量确定的成本策略，且不把 `NSCache` 限制当成硬上限。
- [ ] 可重建缓存与关键数据分离，内存压力下可以安全丢弃。
- [ ] 集合、日志、历史记录和预取队列不会随使用时间无界增长。

## 验证证据

- [ ] 使用固定数据与操作路径记录了改动前后当前值、峰值和操作结束后的回落。
- [ ] Memory Graph 已检查目标对象的强引用路径。
- [ ] Allocations Generations 已验证重复进入/退出后存活对象不会逐轮累积。
- [ ] 关键流程已在支持范围内内存较小的真机验证；模拟器证据单独标明。
- [ ] 画质、缓存命中、网络量、响应速度和功能正确性没有因优化退化。
