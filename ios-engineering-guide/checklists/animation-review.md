# 动画检查

## 行为

- [ ] 动画服务于明确的状态变化，时长和曲线不是无条件套用统一常量。
- [ ] 用户可在动画期间操作时，已定义暂停、接管、反向、取消和完成行为。
- [ ] 重复触发不会让多个 animator 竞争写同一属性。
- [ ] 中断从当前视觉状态连续过渡，位置和速度没有明显跳变。
- [ ] 所有完成、取消和反向路径最终收敛到合法模型状态与视图层级。
- [ ] 转场取消后，交互、命中测试、焦点和可访问性状态恢复正确。

## 性能与适配

- [ ] 动画关键路径没有 I/O、大图解码、重计算或无界主线程工作。
- [ ] 没有按固定帧数推进动画；60 Hz 与 120 Hz 下均按时间/状态正确运行。
- [ ] 已读取并响应 Reduce Motion，为大幅运动提供合理替代效果。
- [ ] 在不同尺寸、旋转、前后台切换和连续操作下无跳变或残留状态。

## 验证

- [ ] 在真实设备以正常速度完成交互验证；慢速动画仅用于辅助观察。
- [ ] 分别在 60 Hz 与支持 120 Hz 的目标设备检查体验。
- [ ] 使用 Hitches 和 Time Profiler 验证主线程与迟到帧；不只检查平均 FPS。
- [ ] 记录可复现操作、设备、系统、构建配置及优化前后证据。
