# 列表滚动检查

## 正确性

- [ ] Cell 使用复用 API，配置幂等，`prepareForReuse()` 能清理残留视觉状态。
- [ ] 异步结果以稳定内容身份校验，不只依赖可能变化的 `IndexPath`。
- [ ] 快速滚动、插入删除和页面退出后，不会错图、闪烁或被过期回调覆盖。

## 关键路径

- [ ] `cellFor...`、布局和绘制路径没有同步 I/O、图片解码或昂贵计算。
- [ ] 滚动回调没有无条件刷新列表、反复失效布局或创建无界任务。
- [ ] 图片和展示数据按实际显示需要准备，缓存有容量与失效规则。
- [ ] 预取不是正确性的前提；未预取时仍能正确展示。
- [ ] 预取、Cell 复用、页面退出和数据失效时会取消不再需要的工作。

## 测量

- [ ] 使用接近生产的数据量和网络条件，在真实性能较弱设备上测试。
- [ ] 覆盖快速正向/反向滚动、停下再滚动、频繁进出页面。
- [ ] 用 Hitches 和 Time Profiler 检查长帧与主线程热点；必要时用 Allocations 检查累积。
- [ ] 60 Hz 与支持 120 Hz 的目标设备分别验证；不以平均 FPS 作为唯一通过条件。
- [ ] 优化前后记录相同场景、设备、构建配置和 hitch 证据。
